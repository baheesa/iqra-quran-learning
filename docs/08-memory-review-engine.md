# 08 - Memory & Review Engine

> "The purpose of review is not to repeat information.
> The purpose of review is to prevent forgetting."

---

# Purpose

The Memory & Review Engine continuously evaluates the learner's understanding and determines:

- What should be reviewed.
- When it should be reviewed.
- Why it should be reviewed.
- How it should be reviewed.

The learner should never have to decide what to revise.

The system quietly prepares every review session automatically.

---

# Philosophy

The learner studies today.

The learner forgets tomorrow.

The application remembers forever.

The Memory Engine exists to bridge that gap.

---

# Forgetting Is Expected

Forgetting is normal.

The system should never treat forgetting as failure.

Instead,

forgetting schedules another review.

Nothing more.

---

# Review Triggers

A review can be triggered when:

The learner forgets a word.

The learner repeatedly asks about a rule.

A confidence score drops.

Several days pass without review.

The learner requests revision.

The learner starts a related lesson.

Review is proactive.

---

# Daily Review Generation

At the beginning of every study session,

the engine prepares:

Today's weak vocabulary

Today's forgotten rules

Today's difficult exercises

Today's recommended revision

The learner simply starts.

No planning required.

---

# Review Before New Learning

Whenever possible,

review should happen before introducing new material.

Daily order

Review

↓

Lesson

↓

Reading

↓

Reflection

This strengthens retention.

# Review Types

---

Rule Review

---

Exercise Review

---

---

---

# Recognition-Based Review

Avoid asking:

"What is the meaning?"

Instead ask:

"Do you recognize this word?"

Recognition is the primary learning goal.

---

# Intelligent Review

Suppose the learner forgets:

ذلك

Instead of reviewing only that word,

the engine may include:

هذا

هذه

ذلك

Those words were learned together.

Review should preserve relationships.

---

# Contextual Review

Words should appear inside verses whenever possible.

Never isolate vocabulary unnecessarily.

Example

Instead of

الحمد

Show

الحمد لله رب العالمين

The learner remembers through context.

---

# Rule-Based Review

If a learner repeatedly struggles with a rule,

the engine should retrieve:

Original Muallim explanation

↓

Original examples

↓

Original exercises

↓

Relevant Quran verses

The learner revisits the curriculum,

not a simplified summary.

---

# Mistake-Based Review

Repeated mistakes deserve priority.

Example

If the learner confuses:

هذا

هذه

ذلك

The engine schedules additional practice.

The learner is never punished.

Only supported.

---

# Reflection After Review

At the end of review,

ask only one question.

Examples

Which word felt easiest today?

Which rule still feels difficult?

What surprised you today?

Reflection strengthens memory.

---

# Review Dashboard

The learner should see only:

Ready Today

Learning

Needs Attention

Recently Mastered

Avoid complex statistics.

---

# AI During Review

The AI should:

Encourage.

Ask questions.

Provide hints.

Correct gently.

Connect lessons.

The AI should not lecture.

---

# Integration with Reading

Reviews should influence Quran reading.

Example

Today's review contains:

الحمد

Later,

the learner encounters الحمد in Surah Al-Fatihah.

The Teacher Engine quietly notes:

"You reviewed this word earlier today."

This reinforces memory naturally.

---

# Integration with Curriculum

The Memory Engine should know:

Current lesson

Completed lessons

Upcoming lessons

Related lessons

Reviews should support the curriculum,

never compete with it.

---

# Long-Term Memory

Eventually,

most words should require no review.

The learner naturally recognizes them while reading.

That is success.

---

# Success Criteria

The learner spends:

Less time reviewing.

More time reading.

Needs fewer hints.

Recognizes more vocabulary.

Feels increasingly confident.

The review engine should slowly make itself unnecessary.

---

# Final Principle

Review should feel like meeting an old friend.

Not taking an exam.

The learner should leave every review session feeling encouraged,

confident,

and ready to continue reading the Quran.
