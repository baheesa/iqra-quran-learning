# 05 - Learner Engine

> "The Learner Engine is the digital memory of the student.
> It remembers everything the learner forgets."

---

# Purpose

The Learner Engine models the learner's understanding over time.

It does not teach.

It does not answer questions.

It simply answers one question:

**What does this learner currently understand?**

Everything the AI does should be based on this answer.

---

# Philosophy

The Quran is constant.

Muallim-ul-Quran is constant.

Only the learner changes.

The Learner Engine exists to continuously update that change.

Every interaction should improve the learner model.

---

# What Is a Learner Model?

The learner model is a living representation of the learner's Quran journey.

It contains:

- completed lessons
- completed units
- current lesson
- current Juz
- current Surah
- current Ayah
- vocabulary confidence
- rule confidence
- review history
- mistakes
- strengths
- weak areas
- study consistency

The model evolves every day.

# Confidence Model

The application should never classify knowledge as simply:

Known

Unknown

Instead use a confidence score.

Example:

0–20

Unknown

21–40

Learning

41–60

Familiar

61–80

Known

81–100

Mastered

Confidence changes continuously.

---

# Confidence Should Increase When

The learner:

Recognizes a word.

Answers correctly.

Reads without assistance.

Completes review successfully.

Explains correctly.

---

# Confidence Should Decrease When

The learner:

Forgets a word.

Requests repeated hints.

Answers incorrectly.

Fails review.

Confuses similar words.

---

# The AI Must Never Forget

The learner should never need to remind the AI.

The AI should remember:

"I struggled with this word last week."

"You mastered this rule two months ago."

"This is your third encounter with this verse."

The learner should feel known.

# Study Consistency

Track consistency.

Do not punish inconsistency.

Missed days should never create guilt.

Instead:

Welcome back.

Let's continue where we left off.

The application should always feel encouraging.

---

# Adaptive Learning

The learner determines the pace.

If understanding is strong:

Move forward.

If understanding is weak:

Increase review.

Never rush.

Never delay unnecessarily.

---

# Forgetting Is Normal

Forgetting is expected.

The engine should treat forgetting as natural.

The solution is review.

Never punishment.

---

# Learner Dashboard

The dashboard should answer only five questions.

1.

Where am I?

2.

What should I study today?

3.

What should I review?

4.

What am I improving?

5.

What comes next?

Nothing more.

---

# The AI Reads the Learner Model

Before answering any question, the AI should know:

What lesson is completed?

What words are weak?

What rules are forgotten?

What is today's lesson?

What is today's Quran reading?

What should be reviewed?

Only then should the AI respond.

---

# Success Metrics

The Learner Engine is successful if:

The learner requires fewer hints over time.

Vocabulary confidence increases.

Rule confidence increases.

Reading becomes smoother.

Review becomes shorter.

The learner naturally reads more Quran with less assistance.

---

# Long-Term Goal

Eventually the learner should:

Read comfortably.

Recognize familiar vocabulary instantly.

Need fewer explanations.

Depend less on AI.

Feel increasingly connected to the Quran.

The Learner Engine should quietly document this transformation.

---

# Final Principle

The Learner Engine does not measure how much the learner has completed.

It measures how much the learner has genuinely understood.

Understanding is the only metric that matters.
