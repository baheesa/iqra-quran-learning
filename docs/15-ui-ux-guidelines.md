# 15 - UI & UX Guidelines

> "The interface should reduce distractions, not increase them. Every design decision should help the learner stay connected with the Quran."

---

# Purpose

This document defines the visual language and interaction principles for the application.

It ensures every screen feels like one coherent experience.

Regardless of who designs or develops the application, these principles must remain unchanged.

---

# Design Philosophy

The application should feel:

• Calm

• Respectful

• Spacious

• Predictable

• Encouraging

• Focused

It should never feel like:

❌ Social media

❌ A game

❌ A productivity dashboard

❌ A chatbot

❌ An AI demonstration

The learner should forget the software and focus on the Quran.

---

# Primary Goal

Every screen should answer one question:

"How can I help the learner continue reading?"

If a feature interrupts reading unnecessarily,

it should be redesigned or removed.

---

# Design Priorities

Priority 1

The Quran

↓

Priority 2

Understanding

↓

Priority 3

Progress

↓

Priority 4

Settings

The Quran is always the center of attention.

---

# Layout Philosophy

Every screen should contain:

One primary action.

One secondary action.

Everything else should remain hidden until needed.

Avoid crowded interfaces.

---

# Visual Hierarchy

Large

Quran text

↓

Medium

Important learning information

↓

Small

Supporting information

↓

Minimal

Statistics

The learner should notice the Quran first.

---

# White Space

Generous spacing is encouraged.

The interface should breathe.

Avoid placing too many controls near the Quran.
