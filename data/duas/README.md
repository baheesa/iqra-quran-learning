# Daily duas data

- `daily-duas.json` — masnoon duas + Qur’anic duas across juz 1–30.
- Qur’anic entries store the **dua excerpt** (not the full surrounding ayah narrative) where possible.
- **Urdu must match the displayed Arabic excerpt**, not the full ayah / multi-ayah block.
- Arabic from local mushaf; Urdu (Jalandhry) via alquran.cloud, then trimmed to the excerpt.
- Memorization: `quran.learning.memorizedQuranicDuaIds`.
